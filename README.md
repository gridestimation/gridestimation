# Grid Estimations — GitHub Pages Website

This package is a complete static website. Upload the CONTENTS of this folder to the repository root.

## Required edits
1. Open `assets/js/site-config.js`.
2. Replace the placeholder email, phone and location.
3. In `robots.txt` and `sitemap.xml`, replace `YOUR-USERNAME` and `YOUR-REPOSITORY`.
4. Replace remote Pexels image URLs with your preferred licensed photos if desired.
5. Replace sample placeholders on `samples.html` with real company samples.

## GitHub Pages
Settings → Pages → Deploy from a branch → main → /(root).

## Included pages
Home, services overview, 8 service detail pages, trades overview, 15 trade detail pages including Solar, locations, resources, pricing, about, samples and contact.
